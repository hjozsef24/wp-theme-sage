# WP Theme Sage

A custom WordPress theme built around reusable, editor-friendly content blocks.

This repository is a source-code showcase. Runtime dependencies, external plugins, configuration, media files, fonts, and build artifacts are intentionally excluded.

## Overview

This WordPress theme is designed to build flexible, structured websites using reusable Advanced Custom Fields (ACF) blocks.
Instead of relying on fixed page layouts, the theme lets editors compose pages from custom blocks while keeping the data, logic, and presentation layers clearly separated.

The structure emphasizes maintainability and scalability.

## Features

- Custom ACF blocks for flexible page building

- Structured content management using Advanced Custom Fields (ACF)

- Reusable Blade templates and view composers

- Modular block architecture with dedicated JavaScript components

- Clean separation of business logic and presentation layer

- Modern asset handling with a frontend build process

## Tech Stack

- **WordPress** (PHP)
- **Sage, Acorn and Blade**
- **Tailwind CSS**
- **JavaScript, jQuery**
- **Advanced Custom Fields** (ACF)
- **Vite**-based frontend asset bundling
- **Custom block architecture and modular PHP structure**
